## What the guard needs that this data cannot satisfy (for the coding agent)

Guard: `scripts/units-lib.mjs` → `licencePending(unit)` = `status !== 'draft' && (blank(ad_license_expiry) || blank(ad_license_qr))`; `isPublic` = not draft, not pending, not expired (Riyadh date). `validateUnits` fails the build on: missing/non-digit `ad_license_number` (6–20 digits), non-calendar `ad_license_expiry`, `ad_license_qr` that is not an existing image file in `content/unit-media/<RT>/` or an https URL ending .jpg/.jpeg/.png/.webp. `syncPublishedMedia` copies `content/unit-media/<RT>/` to `public/units/<RT>/` only for public units. Detail page licence block (`detailLicense`) and card `license` both require a QR URL; without it no licence number is rendered.

1. **`ad_license_qr` is required and there is no QR.** Islam approved full written licence data instead of the QR (Real-Estate Advertising Regulation art. 5/1, publish-batch README). Guard must accept `ad_license_number` + `ad_license_expiry` without QR, and render the number + «ينتهي 15/04/2027م» as text when there is no QR.
2. **No schema field renders advertiser name, FAL licence or WhatsApp per unit.** FAL `1200048445`, office name and `+966535330034` exist site-wide in `content/site.json` (footer/legal block, WhatsApp button). Currently covered by the `features` lines above.
3. **Expiry date is never displayed** (only used for hiding).
4. **Tests to update** (`scripts/units.test.mjs`): `checked-in units 1-10 … stay hidden until expiry + QR are filled` asserts `ad_license_expiry === ''` and `media` `{logo:true}` for RT-006/007/010; `filling expiry + QR publishes …` expects `rt-card-logo` (RT-007 now has photos). With this data: 17 pass / 2 fail (baseline 19/19). `node scripts/build-pages.mjs` succeeds: 0 published units, warnings only.
5. `docs/units.md` still says units 6, 7, 10 have no photos and use the logo card.
6. Live site already carries the commercial registration number in the site-wide schema (`content/site.json` `commercial_registration`); left as is per Fox.
