# الوحدات العقارية

## الوحدات 1–10: تعبئة حقلين فقط لإظهار الوحدة

كل وحدة في ملف مستقل: `content/units/RT-001.json` … `content/units/RT-010.json`. رقم الترخيص مكتوب فيها. الوحدة **مخفية** إلى أن يُملأ الحقلان:

```json
"ad_license_expiry": "",
"ad_license_qr": ""
```

لإظهار وحدة (مثلاً RT-008):

1. احفظ صورة QR من الهيئة العامة للعقار باسم `license-qr.png` (أو `.jpg`/`.webp`) داخل `public/units/RT-008/`.
2. في `content/units/RT-008.json` اكتب:
   ```json
   "ad_license_expiry": "2027-11-04",
   "ad_license_qr": "license-qr.png"
   ```
   التاريخ بصيغة `YYYY-MM-DD` كما في الرخصة.
3. شغّل `node scripts/build-pages.mjs` ثم `node --test scripts/*.test.mjs`.

القواعد (جارد REGA في `scripts/units-lib.mjs`):

- أحد الحقلين فاضي ← الوحدة مخفية (لا بطاقة، لا صفحة، لا خريطة موقع)، والبناء يطبع تحذير `hidden until ...` ولا يفشل.
- الحقل مملوء لكن غلط (تاريخ بصيغة أخرى، ملف QR غير موجود أو ليس صورة، رقم ترخيص غير أرقام) ← البناء **يفشل**.
- تاريخ الانتهاء أقدم من اليوم بتوقيت الرياض ← الوحدة تختفي تلقائياً مع تحذير.
- قسم «الوحدات المتاحة» تحت الهيرو في الرئيسية وزر «شوف الوحدات المتاحة» يظهران فقط إذا وُجدت وحدة واحدة على الأقل مكتملة الرخصة؛ غير ذلك لا يظهر شيء.
- الوحدات 6 و7 و10 بلا صور معتمدة، فتظهر ببطاقة شعار (`"media": { "logo": true }`)، بلا صور مولّدة أو جاهزة.
- النصوص منقولة حرفياً من قسم «الموقع» في مسودات الوحدات. الحقول التي لم يذكرها المدير محذوفة ولا تُرسم. لا أسماء بنوك ولا نسب ولا وعود تمويل في بيانات الوحدات.

## الملف العام

ملف البيانات العام هو `content/units.json`، ويُدمج معه كل ملف في `content/units/`. بعد أي تعديل شغّل:

```bash
node scripts/build-pages.mjs
node --test scripts/units.test.mjs
```

البناء يرفض الملف إذا نقص السعر أو الحالة، أو كان مسار صورة/فيديو غلط، أو تكرر رمز الوحدة. الوحدة ذات `"status": "draft"` تُفحص ثم **لا تُنشر**: لا بطاقة، لا صفحة، لا خريطة موقع.

البطاقة في ملفين فقط (DS v2، فئات `rt-card` و`rt-listing`):

- المكوّن: `scripts/rt-listing-card.mjs`
- التنسيق: `public/assets/rt-listing-card.css`

لا تضف تنسيق `.rt-card` في أي ملف آخر. الشبكة `repeat(auto-fill, minmax(280px, 1fr))` بفراغ 24px، والصورة 4:3. تحت 480px يصبح زر التواصل بعرض البطاقة. التحويم ظل فقط بلا إزاحة. البيع صنف `rt-card--closed`، والمسودة حد متقطع وشارة «مسودة». كل وحدة للبيع: سطر «للبيع» على البطاقة وشارة ذهبية في صفحة التفاصيل. أسماء الرموز الناقصة (`--space-*` و`--font-body` و`--font-display-ar` و`--danger` وغيرها) مضافة في `public/assets/pages.css` دون تغيير القيم الموجودة. المستودع لا يحتوي `tokens.json`. الأيقونات في `public/assets/icons.svg`.

زر واتساب يُبنى تلقائياً من رقم المكتب في `content/site.json`. النص ثابت ولا يُكتب في JSON، لأن نظام العملاء يقرأه كما هو:

`السلام عليكم، جيتكم من الموقع - وحدة RT-001`

## إضافة وحدة

1. أنشئ مجلداً باسم الرمز: `public/units/RT-002/`.
2. ضع فيه `cover.jpg` (الغلاف وصورة المشاركة). أضف صوراً أخرى إن وجدت، بأسماء إنجليزية مثل `inside.jpg`.
3. للفيديو القصير: ضع `tour.mp4` أقل من 3 ميغابايت، و`poster.jpg` كلقطة أولى. للفيديو الأطول ضع رابط `https://` (R2) في حقل `video` بدل الملف، مع `poster` محلي أو رابط `https://`.
4. انسخ العنصر أدناه وألصقه داخل مصفوفة `units` في `content/units.json`. الملف نفسه JSON بلا تعليقات؛ التعليقات هنا للشرح فقط.
5. املأ الرمز والمواصفات. اترك `"status": "draft"` و `"_placeholder": true` إلى أن يعتمد إسلام المواصفات والسعر.
6. عند الاعتماد: احذف `_placeholder`، ضع القيم الحقيقية ورقم الرخصة وQR، وغيّر `status` إلى `available` أو `reserved` أو `sold`.
7. شغّل البناء والاختبار. أصلح أي خطأ يظهر، ثم اطلب مراجعة إسلام قبل الدمج. لا تغيّر الحالة إلى `available` وبياناتها ناقصة أو تجريبية.

## الحقول

| الحقل | مطلوب | القيم |
| --- | --- | --- |
| `code` | دائماً | مثل `RT-001`. حروف إنجليزية كبيرة ثم شرطة ثم 3 أو 4 أرقام. لا يتكرر. |
| `status` | دائماً | `draft` مخفية، `available` متاح، `reserved` محجوز، `sold` مباع. لا حقل لنوع العرض: كل وحدة للبيع |
| `_placeholder` | للبيانات غير المعتمدة | `true` يجبر `status` أن تبقى `draft` |
| `updated` | عند النشر | `YYYY-MM-DD` |
| `type` | عند النشر | نص قصير: فيلا، شقة، دور، أرض، عمارة، محل، استراحة |
| `area_m2` | عند النشر | رقم أكبر من صفر، بالمتر المربع |
| `rooms` | عند النشر | عدد صحيح |
| `bathrooms` | عند النشر | عدد صحيح |
| `floor` | عند النشر | رقم أو نص مثل `الأول` أو `ملحق` |
| `neighbourhood` | أحدهما مع `city` عند النشر | الحي. إن كان `null` لا يُرسم، ولا يُستبدل بأبها |
| `city` | أحدهما مع `neighbourhood` عند النشر | المدينة. إن كانت `null` لا تُرسم |
| `payment` | عند النشر | `cash` كاش، `finance` تمويل |
| `price` | دائماً | `{ "hidden": false, "amount": 430000, "currency": "SAR" }` المبلغ كامل بالريال (يظهر `430,000 ر.س` لا بالآلاف). أو `{ "hidden": true, "amount": null, "currency": "SAR" }` فيظهر «السعر عند التواصل» |
| `seo.title` | عند النشر | عنوان الصفحة |
| `seo.description` | عند النشر | وصف الصفحة |
| `media.cover` | دائماً | اسم ملف داخل مجلد الوحدة، أو رابط `https://` |
| `media.photos` | اختياري | قائمة تشمل الغلاف. إن تُركت تُستخدم صورة الغلاف وحدها |
| `media.video` | اختياري | `tour.mp4` أقل من 3 ميغابايت، أو رابط `https://` |
| `media.poster` | مع الفيديو | صورة اللقطة الأولى |
| `ad_license_number` | عند النشر | رقم رخصة الإعلان في الهيئة العامة للعقار، 6 إلى 20 رقماً |
| `ad_license_expiry` | عند النشر | تاريخ انتهاء الرخصة `YYYY-MM-DD` |
| `ad_license_qr` | عند النشر | صورة رمز QR، ملف داخل مجلد الوحدة أو رابط `https://` |
| `title` | اختياري | عنوان البطاقة. إن تُرك يُبنى من النوع والموقع |

الصور المقبولة: `.jpg` `.jpeg` `.png` `.webp`. المسار المحلي اسم ملف فقط، بلا مجلدات وبلا `..`.

## رخصة الإعلان العقاري

منذ 1 مايو 2026 كل إعلان عقاري في السعودية لازم يظهر رقم رخصة الإعلان من الهيئة العامة للعقار ورمز QR. لذلك:

- أي وحدة ليست `draft` وينقصها `ad_license_number` يفشل البناء. إذا نقص `ad_license_expiry` أو `ad_license_qr` تبقى مخفية بلا فشل، ولا تُنشر أبداً بدون الحقول الثلاثة.
- البطاقة وصفحة التفاصيل تعرضان رقم الرخصة وصورة QR.
- إذا تاريخ الانتهاء أقدم من اليوم بتوقيت الرياض، الوحدة لا تُنشر وتُعامل كمسودة. البناء يطبع تحذيراً ويكمل، ولا يفشل. يوم الانتهاء نفسه ما زال صالحاً.
- شارة `sold` هي «مباع»، وزر التواصل يصبح «تم البيع» وغير قابل للضغط، حتى لا يُفتح طلب على وحدة مغلقة.
- كل بطاقة تعرض «للبيع»، وصفحة التفاصيل تعرض الشارة الذهبية نفسها. لا يوجد حقل `listing_type`.
- المسودة، والبيانات التجريبية، والرخصة المنتهية لا ترسل نص واتساب الخاص بالوحدة.

## RT-001

`RT-001` الآن هي الوحدة 1 الحقيقية (`content/units/RT-001.json`). المسودة التجريبية القديمة وصورها «بيانات تجريبية» حُذفت.

## معاينة المسودة محلياً

```bash
node scripts/build-pages.mjs --preview-drafts
```

هذا يرسم المسودات وعليها شارة «بيانات تجريبية» و`noindex`، للمعاينة فقط. لا تعتمد هذا الناتج. بعدها أعد البناء بدون العلم حتى تُحذف صفحات المسودات:

```bash
node scripts/build-pages.mjs
```

## الفيديو

الفيديو القصير يُضغط إلى MP4 تحت 3 ميغابايت مع صورة poster ويبقى في مجلد الوحدة. الفيديو الأطول يُرفع إلى R2 ويُلصق رابطه `https://` في `media.video` حتى لا يكبر Git. البناء يرفض ملف MP4 المحلي إذا تجاوز 3 ميغابايت.
